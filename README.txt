우리반 퀴즈 - 다른 컴퓨터에서 실행하는 방법
==========================================

[처음 한 번만]
1. python.org 에서 파이썬을 설치해요.
   설치 첫 화면 아래 "Add python.exe to PATH" 칸을 꼭 체크하세요.
2. install.bat 을 더블클릭해요. (퀴즈에 필요한 도구 설치, 인터넷 연결 필요)
3. (인터넷 어디서나 쓰려면) install_tunnel.bat 도 더블클릭해요. (통로 도구 설치)

[같은 와이파이에서 쓸 때]  →  start.bat 더블클릭
 - 검은 창은 게임 끝날 때까지 켜두세요.
 - 진행자 화면: 브라우저 주소창에 localhost:8080/host
 - 참가자는 같은 와이파이에 연결된 휴대폰으로 QR을 찍어요.

[인터넷 어디서나 쓸 때 (LTE/5G, 다른 장소)]  →  start_internet.bat 더블클릭
 - 검은 창이 두 개 떠요 (퀴즈 창, 통로 창). 둘 다 게임 끝날 때까지 켜두세요.
 - 10초쯤 뒤 진행자 화면이 인터넷 주소로 자동으로 열려요. QR에도 그 주소가 들어가요.
 - 통로 창에서 Ctrl + C 를 누르면 통로가 닫혀요. 누르지 마세요.
 - 통로 주소는 켤 때마다 바뀌어요 (QR은 알아서 바뀌어요).
 - 회사/학교 와이파이가 막으면 휴대폰 핫스팟에 컴퓨터를 연결해서 해보세요.

처음 실행하면 윈도우 방화벽 창이 뜰 수 있어요 → "허용"을 눌러주세요.

[꼭 바꿔주세요]
- quiz_game.py 를 메모장이나 IDLE로 열어서 맨 위 HOST_PASSWORD 를 나만 아는 비밀번호로 바꾸세요.

[원래 컴퓨터에서 만든 문제/팀 가져오기]
- 원래 퀴즈 폴더의 quizzes 폴더, teams.json 파일, images/questions 폴더(문제 사진)를
  이 폴더에 그대로 복사해서 덮어쓰면 돼요.

[폴더 구성]
quiz_game.py          퀴즈 프로그램
images/               용강이 그림, 카드 그림 (문제 사진은 images/questions 에 저장돼요)
sounds/               배경음악, 정답 효과음
quizzes/              만든 문제 세트 (처음 실행하면 생겨요)
install.bat           도구 설치 (처음 한 번)
install_tunnel.bat    통로 도구 설치 (인터넷용, 처음 한 번)
start.bat             같은 와이파이용 실행
start_internet.bat    인터넷 어디서나 실행
tunnel.py             통로를 열어주는 작은 프로그램 (start_internet.bat 이 사용)
